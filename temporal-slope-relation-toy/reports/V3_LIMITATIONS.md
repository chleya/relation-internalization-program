# V3 Limitations

Date: 2026-04-28

## 1. Toy World

V3 remains a synthetic diagnostic.

The temporal chain is simplified:

```text
rainfall -> pore pressure -> displacement -> crack/risk
drainage -> pore pressure down
anchoring -> displacement down
```

It is not a numerical slope mechanics model.

## 2. Predefined Relation Links

The relation links are predefined.

The project tests whether agents can use, edit, audit, and act on the links under uncertainty.

It does not test unrestricted discovery of engineering relations.

## 3. Synthetic Noise

Missing sensors, noisy observations, and delayed reports are generated by simple synthetic rules:

```text
missing_rate
noise_rate
delayed_report_rate
```

This is useful for diagnosis but not a real monitoring uncertainty model.

## 4. Rule-Defined Takeover Ground Truth

Takeover labels are generated by rules.

This makes the experiment reproducible, but it also means:

```text
takeover_required is not validated against human engineering judgment.
```

## 5. Audit Is Structured But Still Template-Like

The audit must name uncertain fields and links, but it is still generated from known toy metadata.

V3.1 should test whether audit passes because of templates rather than real uncertainty localization.

## 6. Learned Agent Is Still Narrow

`learned_delayed_links` learns from predefined candidate delays and candidate links.

It is not a general temporal causal discovery system.

## 7. Oracle-Like Components Remain

`delayed_relation_chain` has hand-coded relation structure.

It is an upper-bound diagnostic agent, not a learned engineering model.

## 8. Current Hardening Gap

V3 has not yet been hardened against:

```text
irrelevant missing sensor
benign noise
takeover overuse
false missingness shortcut
audit-template-only behavior
conflicting downstream evidence
```

These belong in V3.1.

## 9. Current Best Limitation Statement

```text
V3 shows a toy separation between temporal relation-chain takeover and temporal memory, but it does not establish real engineering safety, unrestricted relation discovery, or deployment-ready uncertainty handling.
```
