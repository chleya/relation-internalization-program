# R1 Scope: Relation Internalization Agent

Date: 2026-04-29

## 1. Why R1 Exists

V1-V6 built diagnostics, review workflows, governance shells, and audit resolution.

Those are useful, but they are not the core architecture.

R1 returns to:

```text
How can a non-LLM system turn interaction with a world into usable internal
relation structures?
```

## 2. R1 Must Test

```text
active intervention
relation graph learning
relation-guided action
counterfactual prediction
internal relation editing
OOD robustness against surface warning shortcuts
```

## 3. R1 Must Not Become

```text
LLM prompting
engineering review text generation
governance logging
real safety model
general AGI theory
```

## 4. Minimal Architecture

```text
perception: observe process variables
intervention: choose actions that change variables
relation learner: update internal link table
counterfactual simulator: predict next state under intervention
policy: choose action using internal relations
editor: modify internal relation and observe behavior change
```
